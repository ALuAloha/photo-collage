# Composition

## 1. Richness Is Not Element Count

Do not solve a weak composition by continuously adding objects.

Visual richness comes from:

- spatial depth
- scale relationships
- color relationships
- overlap
- visual movement
- negative space
- light/dark contrast

## 2. Build the Visual World

A useful hierarchy is:

**Background World**
↓
**Thematic Middle Layer**
↓
**Core Subject**
↓
**Foreground and Edge Rhythm**

Different layers should have visibly different visual weight.

## 3. Reconstruct the Environment

If the original environment has little visual value, it may be:

- removed
- fragmented
- replaced
- reconstructed

The existence of an object in the source image does not mean it must remain.

Treat the original photograph as a visual material library.

Extract:

- subject
- architecture
- plants
- food
- water
- texture
- shape
- color

Then reorganize them.

## 4. Preserve Relationships

Do not mechanically reproduce every original object.

Preserve key relationships.

For example:

> pavilion + tree + water

may become:

> geometric pavilion structure + botanical graphic texture + large water-colored field

The original relationship should remain understandable.

## 5. Visual Focus

The core subject must have clear visual priority.

Use:

- color contrast
- tonal contrast
- scale
- negative space
- overlap
- background simplification

to reinforce the subject.

## 6. Free Elements

Free elements create rhythm rather than carrying the main narrative.

Add them only when the composition benefits from them.

Never add them merely to imitate a reference image.
