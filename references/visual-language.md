# Visual Language

## 1. Goal

The goal is not:

> real photograph + a few decorations

It is:

> original visual DNA + a newly constructed thematic world

The final image should feel like the source photograph has been redesigned into a coherent visual system.

## 2. Visual Hierarchy

### Large — Establish the World

Use large elements to define the overall space:

- broad color fields
- geometric structures
- large background forms
- spatial divisions
- large-scale textures

### Medium — Establish the Theme

Use medium elements to connect the new world to the source:

- architecture
- plants
- objects
- graphics
- scene structures
- culturally or contextually relevant symbols

### Small — Establish Rhythm

Use small elements to enrich edges and local areas:

- birds
- flowers
- lines
- small graphics
- local textures
- restrained free-form elements

Small elements are not better simply because there are more of them.

## 3. Do Not Copy Reference Motifs

Reference images provide:

- composition language
- color relationships
- spatial hierarchy
- collage methods
- graphic language
- scale relationships

Do not mechanically reproduce:

- cranes
- birds
- lanterns
- a fixed palette
- a fixed geometric shape
- a fixed layout

New elements should emerge naturally from the source image, its subject, and its context.

## 4. Color

Color is part of composition, not a final filter.

Extract:

- primary color
- secondary colors
- accent color
- brightness relationships
- tonal contrast

An accent color may become a visual anchor, but no specific color should be mandatory.

## 5. Coherence

The entire frame should form one visual world.

If it looks like:

> original photo + decorations

the reconstruction is too weak.

If the source story can no longer be identified, the reconstruction is too aggressive.

Target:

> **Story preserved, environment reconstructed.**
